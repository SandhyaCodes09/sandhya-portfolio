## 📌 About The Project

This portfolio website presents my technical skills, projects, education, and experience in a clean and responsive interface.

The goal of this project is to create a professional online presence where recruiters and developers can easily explore my work and learn more about my development journey.

## ⚙️ Run Locally

Clone the repository:

```bash
git clone https://github.com/SandhyaCodes09/sandhya-portfolio.git
```

Navigate to the project:

```bash
cd sandhya-portfolio
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

The application will be available at:

```text
http://localhost:5173
```
